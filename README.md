# CGNiksCustomMaterialVariants
This mod adds several leather, canvas, and rope variants. These can be found from various sources.  
This mod needs to be on both the Client and Server.  
Requires https://github.com/Circl-NoE/ATTMateriaLib, https://github.com/CG-Nik/MaterialDistributionAPI, https://github.com/CG-Nik/DyeingAPI, and https://github.com/CG-Nik/CustomDistributionAPI; all on the Server and Client.  
This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
